# omarchy-dark-voyage-theme

Dark Omarchy theme built around deep sea tones (`#00212e` background, `#eaeee9` foreground, `#c7bfae` accent).

## Install

```bash
omarchy theme install https://github.com/paulnunezm/omarchy-dark-voyage-theme
```

Then pick `dark-voyage` via _Style > Theme_ in the Omarchy menu. Repo name follows the `omarchy-[name]-theme` convention so it shows up as `dark-voyage`.
